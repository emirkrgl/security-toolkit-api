## 🗺️ Roadmap

The planned features and integration steps for the current development phase are as follows:

- [ ] **Network Discovery & Directory Brute-Forcing:** Integrating the `NetDiscover` and `DirBrute` modules into the existing API architecture.
- [ ] **Asynchronous Task Management (Concurrency):** Setting up a Background Tasks infrastructure to prevent long-running scans from blocking the API.
- [ ] **Database Integration (SQLite):** Persistent storage of scan results to allow for historical querying.
- [ ] **AI-Powered Analysis Endpoint:** Utilizing AI to interpret and automatically report obtained vulnerability scan results.
- [ ] **Security & Authentication:** Implementing a JWT (JSON Web Token) based authentication system. 
- [ ] **Containerization:** Dockerizing the entire architecture for platform-independent, one-click deployment.
